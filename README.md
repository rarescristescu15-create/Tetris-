# Tetris Game in C

## Description
This project implements a simple version of the classic Tetris game using C.

## Features
- Falling blocks
- Line clearing
- Score system

## Special Rule
If the player reaches 500 points, they can remove one square from a piece to avoid losing.

## Controls
- A → move left
- D → move right
- S → move down

## How to run
```bash
gcc main.c -o tetris
./tetris
